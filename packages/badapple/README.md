# badapple — 무엇이든 화면으로 쓴다

영상 한 편을 흑백 격자로 굽고, **화면이 아닌 것들에 나눠 그린다.**

이름은 원본 밈(Bad Apple!!)에서 왔지만 **넣는 영상은 아무거나**다. 영상 파일은 이 저장소에
없다 — 쓰는 사람이 자기 것을 고르고, 브라우저 밖으로 나가지 않는다.

## 이게 왜 있나

Bad Apple 문화 = 화면이 아닌 것을 화면으로 쓰기. 오실로스코프·계산기·마인크래프트·깃허브
잔디까지 이미 남들이 다 했다. **엔진은 유니크하지 않다.** 유니크는 「우리만 가진 표면」에서 나온다
— 그래서 이 묶음은 자랑거리가 아니라 **수단**이다. 아무 표면에나 싸게 꽂을 수 있어야 한다.

## 쓰는 순서

```ts
import { sampleVideo, encode, decode, Player, DomTilesSurface } from 'badapple';

// ① 영상 → 흑백 격자 → 한 파일
const sampled = await sampleVideo(videoElement, { width: 64, height: 48, fps: 15 });
const bytes = encode(sampled.frames, sampled);

// ② 풀어서 재생기에 넣는다
const player = new Player(decode(bytes), { loop: true });

// ③ 그릴 곳을 붙인다 (붙이고 떼는 건 언제든 자유)
player.stage.add(new DomTilesSurface({ subdivide: { cols: 6, rows: 6 } }));

// ④ 시계를 넣어 준다 — 재생기는 시계를 스스로 만들지 않는다
player.play(performance.now());
const tick = (now: number) => { player.tick(now); requestAnimationFrame(tick); };
requestAnimationFrame(tick);
```

## 구조가 지키는 것

**① 재생기가 화면을 읽는다 (그 반대가 아니다)** — 화면이 재생기에 맞추면 화면이 인질이 된다.
표면은 실행 중에 위치·크기를 재서 격자를 만든다. 마크업도 스타일도 안 건드린다.

**② 무엇을 액정으로 쓸지 이름으로 안 찾는다** — 선택자를 박으면 화면 개편 한 번에 조용히
아무것도 안 그리게 된다. 대신 모양으로 찾는다: 한 부모 밑에 크기가 고만고만한 형제 무리.
쓸 만한 무리는 **여럿을 합친다** — 하나만 쓰면 화면 구석만 켜져서 「화면이 통째로 액정」이 안 된다.
다만 제일 좋은 무리 점수의 절반 아래는 거른다(들쭉날쭉한 뭉치가 끼면 지저분해진다).
쪼갬도 고정이 아니다 — 놓인 칸 수를 보고 정한다. 큰 버튼 다섯 개짜리 화면과 도구 백 개짜리
화면이 같은 값을 쓰면 한쪽은 반드시 뭉갠다.

**③ 표면이 지킬 약속은 둘뿐** — 「내 격자는 몇 칸이고 화면 어디에 있다」와 「이 칸들을 켜라」.
받은 걸 어떻게 그리든 재생기는 모른다.

**④ 하나가 무너져도 나머지는 그려진다** — 표면이 사라지거나 오류를 던지거나 0개여도 계속 돈다.
장난 하나가 사이트를 멈추면 안 된다.

**⑤ 그림을 늘리지 않는다** — 칸 영역에 억지로 맞추면 화면이 가로로 넓을 때 실루엣이 옆으로
퍼진다. 원본 비율을 지킨 채 넣고 남는 가장자리는 비운다(영화 위아래 검은 띠와 같은 원리).

## 도구가 자기 방식으로 그리려면

덮는 층은 **바닥**이다 — 아무도 신고 안 해도 돌아가게 하는 것. 진짜 목표는 도구가 자기
출력물로 그리는 것이다. 도구 쪽에 재생 관련 코드가 한 줄도 안 남는 게 요점:

```ts
const stop = window.KarmoLabBadApple?.add({
  measure: () => (사용중 ? null : { cols, rows }),   // null = 이번 판은 빠진다
  paint: (p) => { /* 내 방식대로 그린다 */ },
  restore: () => { /* 원래 모습으로 */ }
});
Toolbox.onDispose?.(() => stop?.());
```

재생이 도는지, 껐다 켰는지 도구는 몰라도 된다. 첫 사용처 = 아스키 아트(자기 문자 세트로 그린다).
**쓰는 중이면 빠져야 한다** — 남의 작업물을 덮으면 안 된다.

## 들어 있는 표면

| 표면 | 그리는 곳 | 배치 |
| --- | --- | --- |
| `DomTilesSurface` | 화면에 실제로 있는 칸들 (스스로 찾음) | 모자이크 — 전체 그림의 자기 구역 |
| `TextSurface` | 글자판 · 터미널 · 봇 메시지 | 거울 — 전체를 자기 격자로 |
| `TextSurface` (`ramp`) | 탭 제목처럼 **한 줄뿐인 자리** | 칸마다 채움 높이를 글자 굵기로 |
| `LoadSurface` + `LoadDriver` | **기계 부하** — 하드웨어가 화면 | 세로줄 훑기 |

새 표면은 `Surface` 두 함수만 채우면 된다.

## 부하로 그리기 — 알아 둘 것

부하 그래프는 가로축이 시간이라 **한 순간에 값 하나**만 찍힌다. 그림 한 장을 통째로 넣을 수
없으므로, 그림을 왼쪽부터 세로줄로 훑어 그 줄의 실루엣 높이를 그 순간 부하로 낸다.

- **바탕을 재고 그 위에 그린다.** 기계가 놀고 있어야만 되는 게 아니라 자리만 있으면 된다.
  자리가 없으면 `run()` 이 0 을 내고 **한 줄도 안 태운다** — 자리 없는데 태우면 전부 천장에
  붙어 나와서 멀쩡한 코드가 틀린 것처럼 보인다.
- **조각의 끝을 절대 시각으로 못 박아야 한다.** 남은 만큼 자라고만 하면 타이머가 늦게 깨어난
  만큼 조각이 길어지고 부하 비율이 묽어져, 그림이 통째로 아래로 눌린다.
- **재는 창은 조각 하나 전체**여야 한다. 태우는 동안만 재면 무엇을 시키든 100% 로 나온다.
- 태우는 곳과 그리는 곳을 **나눠라.** 안 나누면 그림이 안 나오는 이유가 부하 때문인지 그리기가
  막혀서인지 구별이 안 된다.
