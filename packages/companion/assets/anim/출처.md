# 애니메이션 출처

`cc0-animations.glb` = **Quaternius — Universal Animation Library (Standard)** 의 Godot용 GLB.

- 라이선스: **CC0** (공개 도메인 — 상업·재배포 포함 자유, 표기 의무 없음)
- 받은 곳: <https://opengameart.org/content/universal-animation-library>
- 만든 곳: <https://quaternius.com/packs/universalanimationlibrary.html>
- 담긴 동작: 46개. 여기서 쓰는 것은 `Idle_Loop` · `Idle_Talking_Loop` 정도.

표기 의무는 없지만 적어 둔다 — 남의 것을 어디서 가져왔는지 모르는 상태로 두지 않는다.

## 왜 이게 그대로 붙나

욘의 골격과 이 동작들이 **같은 계열(Rigify)** 이고, 뼈 이름이 `DEF-*` 로 그대로 겹친다
(실측: 욘 쪽 `DEF-` 뼈 33개, 동작 쪽도 `DEF-head`·`DEF-neck`·`DEF-upper_arm.L` …).
그래서 뼈 이름을 다시 짜 맞추는 일 없이 얹힌다.
