## 📂 Repository Structure

This repository is structured as a monorepo containing multiple applications:

- **`apps/blog/`**: My personal technical blog.
  - Built with [Jekyll](https://jekyllrb.com/) and based on the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme.
  - Contains posts about Game Development, Unity, C#, Computer Science, and more.
- **`apps/karmolab/`**: KarmoLab web application. (Automatically deployed alongside the blog)
