# 오락실 로비

- `game-select-bridge.js` → `app-bridge.js` → `approved-lobby.ts`: 게임 ID와 solo/multi 전달, 같은 출처와 해당 iframe 검증. `arcade.ts`에서 모드별 설정/버튼 표시. 모드 없는 기존 진입은 이전 구성 유지.
- `room-picker.ts`: 종목별 공개 방 4개 단위 페이지, 새로고침, 코드 참가. `readRooms`로 빈 목록/연결 실패 구분. 상세 화면 이탈 시 요청과 이벤트 해제.
- 현재 검사: 타입/빌드/라우팅/방 조회/DOM 행동 통과. 브라우저 연결 끊김으로 모드별 화면 배치 및 이전 모바일 좌표 수정의 최종 실측 미완. 실제 상대와 방 생성/참가 검증 별도.

- 사용자 노출 뒤로가기 번역은 한국어/영어/일본어 모두 오락실 명칭. `arcade.btn.quit`에서 관리.
- 구조 정비 대상: 누적된 시안 화면 전환을 단일 전환 담당으로 이관, 설정/대국/결과의 공통 HUD, 예시 수집 상태와 실제 계정 연결. 전체 정비는 아직 미완.

- `screen-fit.css/js`: 로비 하위 화면의 고정 콘텐츠 영역과 페이지 전환. 옷장 상세, 기원, 결과, 기록, 선물, 배경 설정, 이야기에 적용. 기존 DOM 요소 유지, 키보드 포커스가 이동한 페이지 표시.
- `screen-pages.ts`: 실제 게임 설정과 방 대기 화면의 긴 내용 페이지 전환. 위젯 종료 시 observer 회수.
- 이번 검증: 타입 검사와 빌드 통과. 모바일 옷장/기원 2페이지 전환 확인. 이후 브라우저 연결이 끊겨 기록/선물/배경 설정과 실제 2D/3D 대국 전수 검증 미완. 전체 무스크롤 완료로 간주하지 않음.

- 게임 선택은 `game-select.html`의 승인 페이지 전환 UI. 650px 이하 4개, 나머지 6개씩 표시. `game-select-bridge.js`는 검토 도구를 제외하고 기존 게임 설정으로 연결. 미공개 게임은 준비 중 안내.
- 모바일 공통 흐름 배치의 여백과 55vh 최소 높이는 오락실에서 제외. 콘텐츠 칸 flex 채움 유지.

- 화면 계약: 셸 `layout: full`의 콘텐츠 영역 전체 사용. 로비는 부모 영역 100%, iframe 최소 높이와 창 높이 계산 없음. 브라우저 전체화면 전환이나 레터박스 없음.

- `character-lobby.ts`: 공개 명부와 검색. 게임 시작에서 목록 선택 즉시 기존 설정 진입, 최근 게임 보조 시작.
- `character-lobby.css`: 배경과 인물 분리, 앱 배율을 반영한 가용 높이. 게임 화면 스타일과 분리
- `lobby-music.ts`: 첫 입력부터 기본 배경음, 음소거, 로비 이탈과 숨김 시 정지, 위젯 종료 시 회수
- `approved-lobby.ts`: 승인 로비 전체를 `arcade-lobby/index.html`로 로드. 기존 앱 스타일과 격리, 게임 설정 진입과 최근 기록만 메시지로 연결. 메시지는 같은 origin과 해당 frame에서 온 공개 게임 ID만 허용.
- `arcade-lobby/`: 승인 HTML과 CSS 6개, JS 5개를 유지. 옷장, 이벤트, 메뉴, 기원 연출 포함. 계정/재화/인연은 시안 데이터로 표시. `.local/arcade-art/`는 Git 제외, 앱 배포 입력 밖.
- 그림 원본은 memo 시안 기록에 보존. 새 AI 파일은 코드 repo에 커밋하지 않음. 기존 이미지 이력은 별도.
- 표지 10개는 독립 SVG. 표지 없는 신규 게임은 기존 게임 그림 사용. 목록 데이터는 `catalog.ts`에서 파생
- 일반 로비와 `?all=1` 검사 목록 구분. 숨김 게임 노출 정책 유지
- 확인: 타입 검사, 번들 빌드, 58개 게임 규칙 검사, 브라우저 오목 3D 시작과 로비 복귀, 전체 목록 검색과 요트 설정 연결. 390x844 목록 2열 확인
- 미검증: 전체 UI 자동 검사, 청음, 실제 휴대폰 터치
