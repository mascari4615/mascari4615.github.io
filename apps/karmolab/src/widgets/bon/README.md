# 본 (bon) — 게임 UI 부품 만드는 곳

주소 `/karmolab/#bon`. 정본 TASK = `memo/projects/karmolab/tasks/TASK-KL-254-…`.

이름은 거푸집의 「본」이다. 「먹」이 그림을 그리는 곳이면, 여기는 **찍어내는 틀**을 만드는 곳이다.

## 무엇이 다른가 (먹과)

| | 먹 | 본 |
| --- | --- | --- |
| 들고 있는 것 | 픽셀 판(`Surface`) | 도형 노드 트리 |
| 확대하면 | 깨진다 | 안 깨진다 |
| 고치는 법 | 붓으로 칠한다 | 숫자를 바꾸면 다시 그려진다 |
| 같이 쓰는 것 | — | 되돌리기(`lib/history`) **하나뿐** |

억지로 합치지 않았다. 재보니 공유할 수 있는 건 약 400줄이었고, 합성·저장·붓은 픽셀을 알아야
하는 일이라 뜻이 갈린다. 블렌드·마스크는 SVG 에서 이름만 같고 다른 것이 된다.

## 어디에 뭐가 있나

| 파일 | 하는 일 | 브라우저를 아나 |
| --- | --- | --- |
| `model.ts` | 도형 노드(사각·타원·경로·무리) · 레이어 · 칠 | 모른다 |
| `geom.ts` | 어느 도형을 눌렀나 · 손잡이 여덟 · 끌면 어떻게 되나 · 격자 붙임 | 모른다 |
| `svg.ts` | 화면도 저장도 **같은 길 하나**를 지난다 | 모른다 |
| `parts.ts` | 숫자를 돌려 찍어내는 부품(버튼·패널·게이지) + 변형 N 장 | 모른다 |
| `slice.ts` | 9-slice — 모서리를 고정하고 가운데만 늘리는 셈 | 모른다 |
| `view.ts` | 판 그리기 · 확대/좌표 옮김 · 안내선(고른 테두리·손잡이·격자·경계선) | 안다 |
| `styles.ts` | 꾸밈 한 번만 심기 | 안다 |
| `bon.ts` | 화면 — 도구·오른쪽 패널·레이어·선반 배선 | 안다 |

**규칙 하나**: 화면(`view.ts`·`styles.ts`·`bon.ts`) 말고는 `document`·`window` 를 안 쓴다.
그래서 화면 없이도 답을 맞출 수 있고, 나중에 서버에서 무더기로 뽑을 때 같은 코드가 쓰인다.

**안내선은 그림과 다른 겹**이다(`.bon-guides`). 저장물에 섞이면 안 되는 것들이라 SVG 를 둘로 나눠 둔다.

## 도구

`V` 고르기 · `R` 사각형 · `E` 타원 · `L` 선 · `S` 9-slice 경계 · `Ctrl+Z` 되돌리기 · `Delete` 지우기

## 9-slice — 이 도구가 있는 이유

버튼 한 장을 아무 크기로 늘리면 모서리가 같이 늘어나 뭉개진다. 9-slice 는 아홉 칸으로 나눠
**네 모서리를 그대로 두고** 가장자리와 가운데만 늘린다. 조사해 보니 이걸 정해 주는 벡터
편집기가 거의 없다(Figma·Boxy 둘 다 없다) — 게임 쪽에선 필수인데도.

- 마주 보는 선은 서로를 지나칠 수 없다. 지나치면 가운데가 음수가 되고, 그 그림은 엔진에서
  **뒤집혀 늘어난다**(원인 찾기 어려운 종류의 고장이라 셈에서 막는다).
- 내보낼 때 유니티가 읽는 순서(**왼·아래·오른·위**)로 적는다. 순서를 틀리면 위아래가 바뀐다.

## 선반 (foundry)

만든 것이 내려받기 폴더에서 끝나지 않게 하는 고리. 서버 = `memo/laptop-ops/src/routes/foundry.ts`.

- **구경은 누구나**, **올리기는 열쇠**. 열쇠는 쓰는 사람이 넣고 이 브라우저에만 남는다.
- 그림만 올리지 않는다 — 문서와 9-slice 값을 함께 담아야 남이 「이대로 열기」를 할 수 있다.
- 라이선스는 CC0 하나로 고정. 고르게 하면 아무도 안 고른다.
- 서버가 죽어도 도구는 돈다(검사가 그걸 지킨다).

## 검사

```bash
npm run test:bon          # 단위 — 문서·부품·손잡이·SVG·극단값·레이어·9-slice
npm run test:bon:screen   # 실제 브라우저 — 그어서 도형이 생기는지까지
node scripts/smoke-bon.mjs --shot   # 위와 같되 tmp/bon.png 로 사진을 남긴다
```

## 함정 (실측)

- **위젯에 i18n 카탈로그(ko/en/ja)가 없으면 위젯이 통째로 안 뜬다** (`CatalogLoadError`).
  화면이 안 떠서 알았다 — 새 위젯을 넣을 때 `i18n/{ko,en,ja}/<id>.json` 을 같이 만든다.
- **곧은 선은 한쪽 크기가 0 이다.** 「크기 0 이면 버린다」에 걸려 사라졌다. 선만 길이로 본다.
- **경로·무리는 네모를 적어 넣는 방식으로 못 옮긴다**(점이 여럿·자식이 각자 자리를 든다).
  `translate` 로 민다 — 늘이면 선 굵기·모서리가 같이 일그러진다.
- **여럿이 쓰는 말묶음 파일(`i18n/*/widgets.json`)은 정렬해 다시 쓰지 마라.** diff 가 698줄로
  터져 다른 세션과 부딪힌다. origin 판 위에 키만 얹으면 8줄이다.
