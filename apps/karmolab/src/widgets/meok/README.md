# 먹 (meok) — 그림 도구

레이어로 그리고, 칸으로 움직이는 곳. 주소 `/karmolab/#meok`, 「이미지」 묶음의 **먹** 탭.
정본 TASK = `memo/projects/karmolab/tasks/TASK-KL-240-…`.

## 어디에 뭐가 있나

| 파일 | 하는 일 | 브라우저를 아나 |
| --- | --- | --- |
| `doc.ts` | 문서 모델 — 레이어(불투명도·블렌드·마스크·클리핑) · 셀(hold) · 프레임 | 모른다 |
| `composite.ts` | 합성 — 블렌드 12종 직접 계산 · 어니언스킨 · 스프라이트시트 · 부분 갱신(rect/into) | 모른다 |
| `history.ts` | 되돌리기 — 커맨드 스택 · 더러워진 사각형만 담기 · 이어지는 조정 묶기 | 모른다 |
| `brush.ts` | 붓 — 획 마스크(한 획 한 겹) · 흐름 · 필압 · 손떨림 보정 · 픽셀 모드 | 모른다 |
| `selection.ts` | 선택영역 — 사각/타원/올가미/마술봉 · 더하기·빼기·교집합 · feather | 모른다 |
| `ops.ts` | 자르기 · 크기 · 회전(90도·자유) · 뒤집기 · 보정 5종 · 필터 8종 | 모른다 |
| `pixel.ts` | 픽셀 모드 · 팔레트 · 채우기 · 옛 `.ditherdeck.json` 왕복 | 모른다 |
| `storage.ts` | 문서 접기/펴기(RLE) — 자동 저장과 `.meok` 파일이 같은 길을 쓴다 | 모른다 |
| `rembg.ts` | 배경 지우기 — 워커에서 기기 안 계산, 막히면 뒷길 | 워커만 |
| `view.ts` | 보기 — 속판 · 확대/이동 · 체크무늬 · 격자 · 달리는 개미 | 안다 |
| `meok.ts` | 화면 — 도구·레이어 패널·타임라인·고치기·자동 저장 배선 | 안다 |

**규칙 하나**: 화면(`view.ts` · `meok.ts`) 말고는 `document`·`window` 를 안 쓴다.
검사가 그걸 잠근다(`scripts/test-meok-*.mjs` 첫머리). 덕분에 화면 없이도 답을 맞출 수 있다.

## 검사

```bash
npm run test:meok          # 단위 — 문서·합성·되돌리기·붓·선택·연산·저장
npm run test:meok:screen   # 실제 브라우저 — 그어서 화면이 바뀌는지까지
node scripts/smoke-meok.mjs --shot   # 위와 같되 tmp/meok.png 로 사진을 남긴다
```

실브라우저 검사가 보는 것: 붓 · 되돌리기 · 레이어 숨김이 화면에 반영 · 프레임 · 픽셀 모드 ·
선택영역 밖으로 안 샘 · 필터/보정/회전 · **새로고침해도 그림이 남음** · 가림막 · 글자 ·
붓 담기 · 기울여 돌리기.

## 함정 (실측)

- **화면 픽셀 수로 재지 마라.** 확대율이 조금만 달라도 몇 배씩 튄다 — 밀도(잉크/그림 넓이)나
  확대율 표시로 재라. 정사각 그림은 돌려도 화면 위 크기가 그대로다.
- **저장 표시는 획이 끝난 뒤에 지우고 기다려라.** 그리는 도중에 밀려 있던 저장이 끝나며 뜬
  표시를 보고 새로고침하면 「획이 반만 남았다」는 거짓 빨강이 난다.
- **크기가 바뀌는 연산은 문서 전체에.** 레이어마다 크기가 다르면 합성이 성립하지 않는다.
  레이어 마스크도 같이 옮겨야 한다(안 그러면 판만 잘리고 가림막이 옛 크기로 남는다).
